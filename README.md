# Week 3 Pair Project: Team Profile Page

A shared profile page built by three partners as a Git and GitHub collaboration exercise for the IYF Weekend Academy. Each of us added our own profile card to `index.html` through feature branches and pull requests, and reviewed each other's work.

## What's in this repo

- `index.html`: the shared page, with one `<section>` per team member
- `about-josphine.md`: Josphine's about page
- `README.md`: this file

## Workflow we followed

1. Pulled the latest `main`
2. Created a feature branch for our own change
3. Committed and pushed the branch
4. Opened a pull request into `main`
5. Requested a review from a partner
6. Partner approved, then the PR was merged
7. Deleted the merged branch and pulled the updated `main`
